# إدارات قطاع الري

تطبيق PWA عربي احترافي لعرض إدارات قطاع الري والهندسات التابعة والترع والكباري والمنشآت، اعتمادًا على سجل البيانات المرفق دون إضافة بيانات افتراضية.

## التشغيل

- نسخة GitHub Pages: تُنشر تلقائيًا من الفرع `main`.
- يدعم التثبيت على الموبايل والعمل كتطبيق PWA.
- يعرض 32 إدارة و206 هندسات و4,590 ترعة و21,190 سجل منشأة فريد.
