# إدارات قطاع الري

تطبيق PWA عربي احترافي لعرض إدارات قطاع الري والهندسات التابعة والترع والكباري والمنشآت، اعتمادًا على سجل البيانات المرفق دون إضافة بيانات افتراضية.

## محتوى المنصة

- 32 إدارة عامة.
- 206 هندسات.
- 4,590 ترعة ومجرى.
- 21,190 سجل منشأة فريد بعد إزالة التكرارات المطابقة.
- لوحة قطاع تنفيذية، بحث وفلاتر، جودة بيانات، خرائط، تصدير CSV وطباعة PDF.
- دعم التثبيت على الموبايل والعمل دون إنترنت.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يتم فك ضغط ملف البيانات تلقائيًا قبل التشغيل أو البناء.

## النشر

يُنشر مجلد `docs` تلقائيًا على GitHub Pages من خلال GitHub Actions.
